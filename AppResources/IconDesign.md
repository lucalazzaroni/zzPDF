# zzPDF icon

Created with the built-in image generation tool. The transparent master is
`AppIcon-source.png`; `scripts/build-icon.sh` converts it into the macOS iconset
and ICNS without changing the design. The welcome screen uses the app icon.

## Generation prompt

Use case: logo-brand. Asset type: final macOS app icon for zzPDF, an elegant native PDF editor. Create ONE polished icon only, square canvas, transparent outside the icon. A modern softly rounded square tile, deep midnight indigo with subtle blue lighting, precise clean edges, generous external transparent margin approximately 7%. Center a single sculptural ivory document sheet, simple thin folded upper-right corner and three short tasteful text lines. Over the lower right of the sheet, a bold small vivid periwinkle editing nib/caret motif that communicates editing existing text. Minimal premium modern macOS app design, restrained soft dimensional relief, subtle realistic shadows, large confident shapes readable at 32 pixels. Frontal orthographic view, no perspective tilt. No written words, no letters, no badge, no photorealistic desk, no busy swooshes, no scenery, no glossy plastic pencil, no multiple icons. Balanced negative space. Output the actual usable icon asset with genuine alpha transparency outside tile.
